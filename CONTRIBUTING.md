# Contributing

Thanks for your interest in contributing to the Layered Data Architecture Checklist!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Run `./start-checklist.sh` to install dependencies and start the dev server
4. Make your changes
5. Submit a pull request

## Development

The app is built with SvelteKit 5 + Svelte 5 runes, Tailwind CSS 4, and TypeScript.

```bash
cd app
npm install
npm run dev -- --port 5120
```

## What to Contribute

- Bug fixes
- Accessibility improvements
- New pattern types or new lookup values for existing patterns
- Additional reference architectures
- New export formats
- Documentation improvements
- Translation / i18n

## Code Style

- TypeScript with strict mode
- Svelte 5 runes (`$state`, `$derived`, `$effect`)
- Tailwind CSS for styling
- No unnecessary abstractions — keep it simple
